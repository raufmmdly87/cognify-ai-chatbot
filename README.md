# Cognify AI Chatbot

A Next.js AI chat application deployed on Vercel. Conversations and messages are persisted in a PostgreSQL database through Prisma.

## Live Deployment

Production URL:

https://cognify-ai-chatbot.vercel.app

## Tech Stack

- Next.js
- React
- Prisma
- Prisma Postgres
- PostgreSQL
- Docker Compose
- Vercel
- OpenRouter API

## Local Development

### 1. Install dependencies

```bash
npm install
```
